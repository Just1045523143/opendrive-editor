# 高精路网在线编辑器

基于浏览器的 OpenDRIVE 1.8 编辑工具，支持卫星影像底图绘制、坐标系投影、导入导出。

## 特性

- **几何精度**：Fresnel 积分闭式解求 clothoid（误差 < 5e-14），五种图元（line/arc/spiral/poly3/paramPoly3）全部通过校验
- **坐标系统**：局部横轴墨卡托（TM）、UTM、高斯克吕格、GCJ-02 偏移校正，自动解析 `geoReference`
- **线形生成**：控制点 → 切线圆弧 + 缓和曲线（spiral-arc-spiral），参数可调
- **卫星影像**：多源瓦片（Google/Bing/高德/天地图），Web Mercator → 工程米制 warp
- **交叉口**：逐条点选「进口车道 → 出口车道」建立连接，相邻车道自动并成多车道连接道路；也可点选路臂端点按交规批量生成后再改，连接道路用 Hermite 曲线严格衔接位姿
- **导入导出**：解析 xodr 1.4–1.8、序列化含 `geoReference`、工程文件保存控制点与坐标系
- **2D 渲染**：Canvas 绘制路面/车道线/参考线/控制点/交叉口范围，缩放平移，虚线按真实米制
- **交通设施**：三色交通灯、限速牌、停车/减速让行、禁止驶入，路面转向箭头、停止线和斑马线，可编辑位置并导出
- **3D 预览**：Three.js 带高程与横坡，显示静态交通灯、路牌和路面标记
- **交互工具**：绘制道路、交叉口、车道连接、选择、拖拽控制点、车道编辑、车道段切分、测量

## 技术栈

- **前端**：Vite 8 + TypeScript 5.9，零框架（原生 DOM + Canvas）
- **数学库**：自研 Fresnel / clothoid / 弧长反演，无第三方几何依赖
- **投影库**：proj4 2.21（仅坐标变换，几何算法自研）
- **3D**：three 0.185（预览用）

## 使用指南

### 1. 新建道路
1. 切换到「绘制道路」工具（工具栏或快捷键 `D`）
2. 在影像上点击放置控制点（至少 2 个）
3. 右键或按 `Enter` 完成绘制
4. 道路自动生成缓和曲线与圆弧

### 2. 编辑道路
- **选择**：点击道路或控制点
- **拖拽控制点**：按住方形控制点移动，线形实时更新
- **拖拽渐变手柄**：选中车道后，拖动琥珀色圆形手柄调整车道渐变的起点与长度
- **车道**：在右侧属性面板修改车道数、宽度、标线类型
- **删除**：选中后按 `Delete`

**先让各进口道的端点止于路缘石**，不要交汇于一点，中间的空腔留给连接道路（否则连接道路退化）。

路口的内容就是一组「进口车道 → 出口车道」，两条路子都是往这组里加东西，可以混用。

#### 手工连车道（快捷键 `L`）

渠化怎么划就怎么连，适合多车道左转、禁某个方向这类实际路口。

1. 切换到「车道连接」工具，各可通行车道的端部出现手柄：绿色驶入路口、蓝色驶出，箭头指车流方向
2. 先点进口车道，再点出口车道，连接立即生成。未选中路口时会自动新建一个（按 `N` 可另起一个）
3. 手柄重叠时按 `Tab` 轮换候选，`Esc` 取消当前起点

相邻车道会自动合并成一条多车道连接道路——连了三条相邻车道就是一条路三条车道。在面板上删掉中间那条时，它会自动拆成两条。

#### 批量生成（快捷键 `J`）

规整路口起草用，车道配对按几何推测，产出当草稿看。

1. 依次点击各进口道靠路口一侧的端点，绿色圆环与箭头标示已选中的路臂与驶入方向
2. 按 `Enter` 生成。四岔口产出 16 条转向（直行 4×2 车道、左转 4、右转 4、掉头 4），T 形路口 9 条
3. 在右侧「交叉口」面板逐条核对，删掉实际不允许的转向

启发式配对参照实际交规：

| 转向 | 判定 | 车道配对 |
|---|---|---|
| 右转 | 夹角 < −30° | 最外侧一条到最外侧 |
| 直行 | 夹角 ±30° 内 | 由内向外逐条对齐 |
| 左转 | 夹角 > +30° | 最内侧一条到最内侧 |
| 掉头 | 夹角 > 150° 或同一路臂 | 最内侧一条到最内侧 |

让行关系按进口车道数推断（多者为主路）；车道数相同时留空，由你手工指定。

#### 交叉口面板

列表按车道连接组织，每行形如 `R1@终.-1 → R3@终.1`，右侧徽章标出所属连接道路——徽章相同的几行就是同一条路上的几条车道。点 `×` 删掉一条，点「补全缺失转向」在现有路臂间按启发式补齐（不覆盖已手工连的）。

### 4. 坐标系设置
- 右侧「工程」面板 → 坐标系
- 选择「局部 TM」「UTM」或「高斯克吕格」
- 输入原点经纬度（默认北京天安门）
- 界面显示原点处的尺度因子（1 = 无变形）

### 5. 卫星影像
- 右侧「图层」面板 → 影像源
- 切换 Google/Bing/高德/天地图
- 调整不透明度与层级偏移
- 影像自动按坐标系投影到工程米制

### 6. 导入导出
- **导入 xodr**：工具栏「打开」→ 选择 `.xodr` 文件
- **导出 xodr**：工具栏「导出 xodr」→ 下载 `.xodr`
- **工程文件**：「保存工程」→ `.odrproj` JSON（含控制点、坐标系、图层配置）

## 添加交通设施与路面标记

点击左侧工具栏「🚦 交通设施」（快捷键 `F`），在弹出的图标面板选择类型，
然后在道路或路旁单击放置，无需先选中道路。悬停显示设施预览及所属道路的 s/t。
支持连续点击添加，`Esc` 或再次点击工具图标返回选择工具。开启工具会退出 3D 预览，
回到可点选的俯视画布，并开启设施显示图层。

放置位置自动计算 `s/t`；自动朝向根据点击所在道路侧及 RHT/LHT 判断，
也可在放置面板指定沿 +s 或 −s。参考线两侧重合的道路优先匹配已选道路，
具体道路以悬停提示为准。只允许放置在道路横断面边缘以外 8 米内，
超出道路端点切线方向 0.15 米的点击拒绝放置。
添加后自动选中所属道路，在右侧「交通设施 / 路面标记」展开设施条目，
修改 `s`、`t`、`zOffset`，角度输入使用度。
`orientation` 表示信号适用的行驶方向；`hOffset` 调整灯/牌朝向，`pitch`、`roll` 调整倾角。
支持删除、撤销和重做。俯视图可在图层面板关闭设施显示，3D 预览默认显示全部设施。
3D 中灯和路牌带有固定 28 像素的位置图标，便于在远景或背面观察时定位；
交通灯同时显示灯壳和支杆。工具栏「3D 预览」在当前为 3D 模式时保持高亮，点击返回俯视图。

移动已有设施：在俯视图切换到「选择」（`V`），单击灯/路牌图标或地面标记即可选中，
右侧展开对应属性。按住左键拖动，预览新的 `s/t`，松开提交一次修改；`Esc` 取消拖动，
`Ctrl+Z` 撤销。拖动限定在原所属道路内，超出可放置范围时保持原位；高度、朝向及其他属性保留，
可在右侧单独调整。`Delete` 删除选中的设施。3D 预览当前仅用于观察，拖动在俯视图操作。

首批预设：三色灯、限速牌、停车让行、减速让行、禁止驶入、直行/左转/右转/
直行左转/直行右转箭头、停止线、斑马线。牌面与灯为简化静态图标，不显示实时灯态。
不自动把道路限速变成实体路牌。支持识别 Town 地图中的 `Speed_N` 限速对象；
未知国家的信号编码保留原始导出数据，不猜测图标。

路牌使用 DE 信号目录（274/206/205/267），三色灯使用 OpenDRIVE 1000001。
路面箭头导出为 `object type="roadMark"`，停止线为 `subtype="signalLines"`，
斑马线为 `object type="crosswalk" subtype="zebra"`，同时导出轮廓与白色材质。
新增路面预设时文件版本至少设为 1.8；编辑器已有图标不代表所有下游都支持该类型。

导入后的非预设轮廓仍原样保留，预览对已识别类型使用示意图案。
目前没有车道适用范围、停止线与信号关联、控制器分组的编辑入口；
这些已有 XML 子元素继续透传。图形不会自动生成转向连接或 Apollo overlap。
红绿灯相位/配时、CARLA 车型资产匹配、imap 转换后的交通规则需另行联调。

## 架构

```
src/
├── core/               # OpenDRIVE 核心
│   ├── math/          # 向量、角度、坐标变换
│   ├── geometry/      # Fresnel、clothoid、五种图元求值、线形生成
│   ├── model/         # 数据模型（Road/Lane/Geometry）
│   └── xml/           # xodr 解析与序列化
├── geo/               # 地理层
│   ├── projection.ts  # 坐标系（TM/UTM/GK）+ proj4 封装
│   ├── gcj02.ts       # 中国坐标偏移
│   ├── tiles.ts       # 瓦片计算与多源配置
│   └── reproject.ts   # 文档坐标系切换
├── editor/            # 编辑器
│   ├── app.ts         # 主应用装配
│   ├── viewport.ts    # 视口相机（米 ↔ 像素）
│   ├── renderer.ts    # 2D Canvas 渲染
│   ├── tileLayer.ts   # 瓦片图层（Web Mercator warp）
│   ├── store.ts       # 文档状态 + 撤销重做
│   ├── roadFactory.ts # 道路工厂（线形 + 车道）
│   ├── tools/         # 交互工具（绘制/选择/交叉口/车道连接/测量/分割）
│   ├── connector.ts   # 连接道路几何（两条路径共用）
│   ├── laneConnect.ts # 车道级连接：车道对为基元，整体重建
│   ├── preview3d.ts   # Three.js 3D 预览
│   └── project.ts     # 工程文件（.odrproj）
├── ui/                # UI 组件
│   ├── dom.ts         # DOM 辅助函数
│   ├── panels.ts      # 右侧面板（工程/图层/校验）
│   ├── inspector.ts   # 属性检查器
│   └── styles.css     # 全局样式
└── main.ts            # 入口
```

## 测试

```bash
npm test
```

292 项，覆盖：
- **几何层**：Fresnel 精度 5e-14，五种图元 RK4 对照，spiral 曲率不变量，弧长反演自洽
- **投影层**：TM/UTM/GK 尺度因子、往返互逆、GCJ-02/BD-09 精度、瓦片计算
- **线形生成**：控制点 → spiral-arc-spiral，首末切线吻合、曲率连续
- **交叉口**：转向分类、进出车道判定、T/四/五岔口生成、退化情形拒绝、删除后无悬空引用
- **车道级连接**：合并与拆分、删中间一条、方向与类型校验、整体重建幂等、连接道路 id 复用、手柄拾取
- **往返测试**：解析 → 序列化 → 再解析，几何一致、序列化幂等
- **集成测试**：线形生成 → 道路工厂 → 导出 xodr → 导入 → 几何验证

交叉口工具本体在 Node 下用桩上下文驱动，覆盖真实用户路径而非仅规则。

## 已知限制

- **交叉口**：自动配对为单一策略（右转最外/直行对齐/左转最内），要改配对需手工连车道；无导流线、停止线、信号灯配时；无环岛专用生成
- **信号与控制器**：常用信号可添加并编辑位置；控制器、信号关联和车道适用范围仅保留导入数据
- **校验器**：27 类规则，覆盖几何连续性、车道编号、连接引用、交叉口拓扑；未覆盖全部 xodr 约束
- **瓦片缓存**：仅内存 LRU，刷新页面重新加载
- **影像源**：默认 Esri，其余源需自行确认授权
